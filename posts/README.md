# Posts

英文社交平台的发布稿。**完整的英文解读在各分类目录下的 `*.en.md`**，这里只放压到平台字数上限内的发布版本。文件名与中文解读一一对应，分隔线 `---` 之后是**可直接复制粘贴的纯正文**；分隔线之前放配图引用。

## 写作约定

- **全文英文**，覆盖中文稿的所有章节（方法分步、A/B 结果、心得、愚见），不做「爆款化」改写
- **字符上限 3000**（多数平台的硬限制，超出无法发布）。写作时按 **2750** 预算，给标签留空间
- 不用 Markdown 语法（发布端不渲染），不用 LaTeX，公式转成文字描述
- 去掉公众号专属内容：求关注、铁粉群、二维码、推荐阅读

## 发布清单

**原则：帖子必须自足。** 3000 字符内把核心讲完，不依赖任何点击。不写成「导读 + 长文」——带链接的帖子会被降权，读者还要多点一次，两道损耗叠加，总阅读量不如一条自足的帖子。

1. **正文不放任何链接**，包括论文 DOI。正文只写论文名和会议，链接统一放第一条评论
2. **第一条评论**放两个链接：论文原文 + 本仓库地址（顺带给仓库引流）
3. **@ 原作者**：在编辑框输入 `@` 后从下拉选择，直接粘贴文字不会触发通知
4. 话题标签 3-5 个，含公司名（如 `#Pinterest`）和会议（如 `#SIGIR2026`），已写在文件末尾
5. **配图**：文件开头若有图片引用，发帖时作为附件上传；正文从分隔线 `---` 之后开始复制

> 第一条评论里的仓库链接指向的是 `*.en.md` 完整版——那里有帖子放不下的愚见和细节。即便如此，帖子本身仍要能独立读完。
