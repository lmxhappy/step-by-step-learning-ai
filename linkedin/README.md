# LinkedIn Posts

公众号解读文章对应的英文 LinkedIn 版本。文件名与解读文章一一对应，内容为**可直接复制粘贴的纯正文**（已含 hashtag），不要在里面写备注。

## 写作约定

- **全文英文**，覆盖解读文章的所有章节（方法分步、A/B 结果、心得、愚见），不做「爆款化」改写
- **字符上限 3000**（LinkedIn 硬限制，超出无法发布）。写作时按 **2750** 预算，给 hashtag 和 @ 留空间
- 不用 Markdown 语法（LinkedIn 不渲染），不用 LaTeX，公式转成文字描述
- 去掉公众号专属内容：求关注、铁粉群、二维码、推荐阅读

## 发布清单

1. **正文不放链接**。LinkedIn 对带站外链接的帖子降权，arXiv 链接发完后放**第一条评论**
2. **@ 作者**：在 LinkedIn 编辑框输入 `@` 后从下拉选择，直接粘贴文字不会触发通知
3. hashtag 3-5 个，已写在文件末尾
