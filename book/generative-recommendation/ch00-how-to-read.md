# 第 0 章 · 怎么读工业生成式推荐论文

> 状态：草稿 v0.1 · 全书总纲

## 0.1 为什么另起炉灶

经典搜广推书已经很多：双塔召回、特征交叉、损失与样本、超长序列……这些仍然有用，但 **2010s–2020s 前半的主叙事是「打分 / 排序」**。

生成式推荐换了一套问题提法：

- 不是只给候选打分，而是 **直接生成 item 标识（常为 SID）或整页/序列**  
- 训练与服务更像语言模型：自回归 / 扩散 / 重排生成  
- 工业论文开始密集出现：Reason 离线注入、生成式重排、query 生成、大 beam serving  

所以本书不重写一本 CTR 大全，只帮你建立 **新范式下的阅读与上线判断**。

## 0.2 核心公式

**工业生成式推荐落地 = 选对论文 × 读准指标 × 裁成可上线的一刀**

### 选对论文

优先：**有公司作者 + 有线上数字 + 生成/SID/LLM-for-rec 主线**。  
纯高校、无产业信号的，当扩展阅读，不当立项依据。

### 读准指标

每篇至少问清：

1. 指标名字背后的业务含义（有效消费？曝光转化？GMV？Long Views？）  
2. 分母是用户、请求还是 item？  
3. 「新」是新用户还是新 item？  
4. 对照是谁（原生产生成器？原精排？）  
5. 文中有没有点名 App——没有就不要脑补  

### 裁成可上线的一刀

工业稿常把召回 / 精排 / 生成器 / tokenizer 捆成 framework。阅读时默认：

- **可替换背景**：换成别家召回/精排，故事往往仍成立  
- **增量一刀**：本篇真正新的条件、损失、解码或 serving 改动  

上线时先问：这一刀是否要求请求路径变重？能否离线/近线？失败能否回退？

## 0.3 四块阅读模板（后文每章复用）

1. **场景**  
2. **增量一刀**  
3. **指标怎么读**  
4. **能不能上（延迟 / 刷新 / 回退）**

## 0.4 你读完本章应能做什么

- 把一篇工业生成式推荐论文压成「一刀 + 三个数 + 一个上线风险」  
- 拒绝用经典 CTR 书的目录，硬套 SID 生成故事  
- 知道本书后面章节是在练同一套判断肌肉，而不是堆模型名词
