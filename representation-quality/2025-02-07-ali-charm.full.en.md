CHARM: Cross-Modal Hierarchical Attention for Recommendation with Multi-Modal Data

Link: https://arxiv.org/pdf/2501.18662

Company: Alibaba

Area: multimodal

Overview: Alibaba's latest paper on multimodal recommendation. CHARM proposes a cross-modal hierarchical attention model that combines multimodal data with an attention mechanism to achieve efficient multimodal recommendation modeling. Specifically, CHARM first converts the multimodal data into embedding vectors, then uses cross-modal attention to capture the interactions between modalities. CHARM also introduces a new hierarchical attention module that combines the multimodal data with the attention mechanism to achieve efficient multimodal recommendation modeling.
