Hiformer: Hierarchical Attention-based Feature Interaction Modeling

Link: https://arxiv.org/pdf/2501.19060

Company: NetEase

Area: feature interaction

Overview: NetEase's latest paper on feature interaction. Hiformer proposes a hierarchical attention-based feature interaction model that combines feature interaction with an attention mechanism to achieve efficient feature interaction modeling. Specifically, Hiformer first converts features into embedding vectors, then uses a hierarchical attention mechanism to capture the interactions between features. Hiformer also introduces a new feature interaction module that combines feature interaction with the attention mechanism to achieve efficient feature interaction modeling.

Credibility: offline
