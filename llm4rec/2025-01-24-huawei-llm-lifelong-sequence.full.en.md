Full-Stack Optimized Large Language Models for Lifelong Sequential Behavior Comprehension in Recommendation

Link: https://arxiv.org/pdf/2501.13344

Company: Huawei

Area: Long sequences + LLM

Overview: Strengthens large language models so they handle long sequences better. The problem is that LLMs cannot effectively extract useful information from the plain-text context of long user behavior sequences, even when that context is far shorter than the LLM's context limit. This paper tackles it in two ways: (1) SUBR: selecting semantically relevant items from the long sequence; (2) enhancing the LLM itself. For the latter, it aligns the item ID information from traditional recommendation models with the items' textual information, giving the LLM better awareness and handling of ID information.
