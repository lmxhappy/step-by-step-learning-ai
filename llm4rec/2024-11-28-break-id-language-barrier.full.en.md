> [中文版](2024-11-28-break-id-language-barrier.md)

1 Break the ID-Language Barrier: An Adaption Framework for Sequential Recommendation

Link: https://arxiv.org/pdf/2411.18262#page=5.24

Company: Huawei

Area: behavior sequence + LLM

Overview: connects the recommendation model and the large language model. A prompt for the LLM is built from the user behavior sequence, and the LLM's training is influenced through dimension alignment, layer-wise embedding refinement, layer-wise distribution alignment and similar methods, which improves the LLM's recommendation performance. This can be seen as a form of distillation.

Credibility: offline validation

Recommendation: read if you have time.
