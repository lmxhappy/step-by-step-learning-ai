# Recommendation algorithm paper

1 Are Longer Prompts Always Better? Prompt Selection in Large Language Models for Recommendation Systems

Link: https://arxiv.org/pdf/2412.14454

Company: NEC

Area: LLM recommendation

Overview:

The paper studies how to choose suitable prompts for LLM-based recommender systems (LLM-RSs).

(1) Prompts matter: in LLM-RSs, prompt choice is critical to recommendation accuracy.

(2) No universal prompt: no single prompt performs best in all cases; prompt choice has to take the dataset's characteristics into account.

(3) Prompt selection method: the paper proposes a prompt selection method that achieves high accuracy with minimal validation data. In short, from a set of prompt templates, it picks the best prompt for each dataset through automated trials.

(4) Cost-effective strategy: the paper also proposes using a high-performance, low-cost LLM to reduce the cost of prompt exploration.

Credibility: offline
