CoRAL: Collaborative Ranking with Large Language Models

Link: https://arxiv.org/pdf/2501.18937

Company: Huawei

Area: LLM + ranking

Overview: Huawei's latest paper on LLM-based ranking. CoRAL proposes a collaborative ranking method based on large language models, combining LLMs with collaborative filtering to achieve efficient ranking. Specifically, CoRAL first converts the user behavior sequence into embedding vectors, then uses the LLM to capture changes in user interest. CoRAL also introduces a new collaborative ranking module that combines the LLM with collaborative filtering to achieve efficient ranking.
