## 内容摘要

本文解读 Meta 的 SilverTorch（arXiv:2511.14881）：一套完全基于 GPU 与 PyTorch 的统一推荐系统，把召回与粗排合并进一个模型，将 ANN 搜索、倒排过滤、缓存等原本独立的外部服务全部重构为模型内部的 PyTorch 算子，实现全链路 GPU 算子化，报告吞吐提升 23 倍、性价比提升 13 倍、召回率提升 28.2%。

核心创新四点：（1）“索引即模型”范式——索引封装为 torch.nn.Module，用户特征进来后在 GPU 上一次 forward 跑完用户塔、ANN 搜索、特征过滤与重排，避免跨服务 RPC 与版本不一致；（2）Bloom Index——借鉴 BitFunnel 的 GPU 特征过滤索引，查询变为位运算，内存占用为倒排索引的 1/4、速度最高提升 500 倍；（3）联合优化——先用 ANN 圈定候选再做 Bloom 过滤，配合 Embedding 的 Int8 量化与融合 Kernel；（4）在召回阶段引入 OverArch 与 Value Model 等“精排级”能力做多目标融合，提升召回与精排的目标一致性。

作者心得三点：技术栈向 All-in-PyTorch 收敛对中小厂友好；GPU 算力红利让复杂模型得以从精排前置到召回层；Bloom Filter 在 GPU 的 SIMT 架构上胜过倒排索引，是“算法适配硬件”的典型案例。可信度：生产（Meta 内部已服务数十亿用户）。页面评级：强烈推荐（特别是关注推荐架构、GPU 高性能计算的同学）。
