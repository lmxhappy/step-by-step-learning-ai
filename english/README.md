# English Versions

公众号解读文章的英文版。文件名与中文解读一一对应，分隔线 `---` 之后是**可直接复制粘贴的纯正文**；分隔线之前放配图引用。

## 写作约定

- **全文英文**，覆盖中文稿的所有章节（方法分步、A/B 结果、心得、愚见），不做「爆款化」改写
- **字符上限 3000**（多数平台的硬限制，超出无法发布）。写作时按 **2750** 预算，给标签留空间
- 不用 Markdown 语法（发布端不渲染），不用 LaTeX，公式转成文字描述
- 去掉公众号专属内容：求关注、铁粉群、二维码、推荐阅读

## 发布清单

1. **正文不放链接**。带站外链接的帖子通常被降权，论文链接发完后放**第一条评论**
2. **@ 原作者**：在编辑框输入 `@` 后从下拉选择，直接粘贴文字不会触发通知
3. 话题标签 3-5 个，已写在文件末尾
