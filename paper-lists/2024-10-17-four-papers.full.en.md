# Recommendation paper list (2024.10.17)

1. https://arxiv.org/pdf/2410.12228

Triple Modality Fusion: Aligning Visual, Textual, and Graph Data with Large Language Models for Multi-Behavior Recommendations

a. Walmart + multimodal + LLM.

b. Injects three kinds of information into the model at the same time.

2. https://arxiv.org/pdf/2410.12229

Comprehending Knowledge Graphs with Large Language Models for Recommender Systems

a. Tencent + knowledge graph + LLM

3. https://arxiv.org/pdf/2410.12519

RosePO: Aligning LLM-based Recommenders with Human Values

a. Tencent + Xiangnan He + LLM

b. Not a direction I follow; if interested, read it yourself.

4. https://arxiv.org/pdf/2406.00333

A Practice-Friendly LLM-Enhanced Paradigm with Preference Parsing for Sequential Recommendation

a. Huawei + LLM + behavior sequence

b. Using LLMs to strengthen interest modeling over behavior sequences.
