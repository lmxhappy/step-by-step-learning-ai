# Recommendation paper list (2024.10.29)

> [中文版](2024-10-29-three-papers.md)

> Source: WeChat post https://mp.weixin.qq.com/s/sW9zUgKJYrN1_tNX8g_Hgg, published 2024-10-28.

1. Bi-level User Modeling for Deep Recommenders

a. Link: https://arxiv.org/pdf/2410.20730

b. Company: Xiaohongshu

c. Direction: user modeling. Uses group embeddings to improve the model.

d. Rating: worth reading

2. Beyond Positive History: Re-ranking with List-level Hybrid Feedback

a. Link: https://arxiv.org/pdf/2410.20778

b. Company: Huawei

c. Direction: rerank + list-wise.

d. Rating: read if you have time

3. RECFLOW: AN INDUSTRIAL FULL FLOW RECOMMENDATION DATASET

a. Link: https://arxiv.org/pdf/2410.20868

b. Company: Kuaishou

c. Direction: releases a dataset. Its biggest highlight is that it includes unexposed items that were filtered out, so it can be used to develop models for multiple pipeline stages. By comparison, earlier datasets only contain exposed samples. It is also huge: 38M interactions, 42K users, 9M items. Deep respect to Kuaishou.

d. Rating: worth reading
