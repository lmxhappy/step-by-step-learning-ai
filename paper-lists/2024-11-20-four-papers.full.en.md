# Recommendation paper list (2024.11.20)

> [中文版](2024-11-20-four-papers.md)

> Source: WeChat post https://mp.weixin.qq.com/s/v7PqILZPlUZWOpSqpVnnNQ, published 2024-11-20.

1 MultiBalance: Multi-Objective Gradient Balancing in Industrial-Scale Multi-Task Recommendation System

Link: https://arxiv.org/pdf/2411.11871

Company: Meta

Direction: multi-task learning

Overview: multiple tasks often face negative transfer; this paper proposes a gradient balancing method.

Credibility: online validation

Rating: worth a look

2 Multi-Grained Preference Enhanced Transformer for Multi-Behavior Sequential Recommendation

Link: https://arxiv.org/pdf/2411.12179

Company: Ant Group

Direction: behavior sequence modeling

Overview: uses transformers for multi-behavior sequence modeling.

Credibility: production

Rating: worth a look

3 Towards Unifying Feature Interaction Models for Click-Through Rate Prediction

Link: https://arxiv.org/pdf/2411.12441

Company: Tencent

Direction: feature interaction

Overview: proposes a general framework for explicit feature interaction.

Credibility: production

Rating: read if you have time

4 TSPRank: Bridging Pairwise and Listwise Methods with a Bilinear Travelling Salesman Model

Link: https://arxiv.org/pdf/2411.12064

Company: NVIDIA

Direction: Pairwise + Listwise

Overview: proposes a method that does pairwise ranking and listwise ranking at the same time.

Credibility: offline

Rating: read if you have time.
