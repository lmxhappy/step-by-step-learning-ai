Oracle-guided Dynamic User Preference Modeling for Sequential Recommendation

Link: https://arxiv.org/pdf/2412.00813

Company: Microsoft

Overview: Existing sequential recommendation methods only use past information extracted from the user's interactions before the current one. This paper treats future information (i.e., the items the user interacts with after this sample in time) as a kind of posterior information, extracts it, and uses it to guide the model's training on past information, hoping to capture the dynamic changes of user preferences more comprehensively.
