MISS: Multi-Interest Self-Supervised Learning for Sequential Recommendation

Link: https://arxiv.org/pdf/2501.19207

Company: Xiangnan He. There are Meta authors on it, but not the first or corresponding author. By comparison, Xiangnan He is the bigger name.

Area: sequential recommendation

Overview: This paper proposes a multi-interest self-supervised learning method: it converts the user behavior sequence into multiple interest representations, then uses self-supervised learning to capture changes in user interest. Specifically, MISS first converts the user behavior sequence into embedding vectors, then extracts multiple interest representations of the user with a multi-interest extraction module. MISS also introduces a self-supervised learning module that combines the user behavior sequence with the interest representations to achieve efficient sequence modeling.
