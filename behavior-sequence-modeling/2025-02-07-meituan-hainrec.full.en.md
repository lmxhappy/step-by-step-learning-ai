HAINRec: Hierarchical Attention Interaction Network for Sequential Recommendation

Link: https://arxiv.org/pdf/2501.19158

Company: Meituan

Area: sequential recommendation

Overview: Meituan's latest paper on sequential recommendation. HAINRec proposes a hierarchical attention interaction network that combines sequence modeling with an attention mechanism to achieve efficient sequence modeling. Specifically, HAINRec first converts the user behavior sequence into embedding vectors, then uses a hierarchical attention mechanism to capture interest changes at different levels of the sequence. HAINRec also introduces a new interaction module that combines sequence modeling with the attention mechanism to achieve efficient sequence modeling.

Credibility: offline
